## About The Project

The original eMule landing page carries strong sentimental value for those who experienced the early era of P2P file sharing. However, its visual layout has become severely outdated.

Rather than adopting modern web trends—which often lean toward flat, overly minimal, and identity-lacking interfaces—this project reimagines the eMule landing page through a lens of **technological nostalgia**. It draws heavy inspiration from late 2000s tech aesthetics (Web 2.0 / Y2K / Frutiger Aero era), capturing how Gen Z envisioned and experienced early digital networks.

### Design Decisions & Intentionality

* **Interactive Language Scroller:** Although modern browsers offer automatic translation, eMule’s core philosophy has always been about **universal access and community-driven sharing**. Inspired by the flag icons on the original site, a custom horizontal language carousel was built to showcase multi-language support (21 languages) and emphasize global connectivity.
* **Skeuomorphic & Glassmorphic Visuals:** Translucent containers, bold glow effects, and vibrant color gradients were chosen deliberately to evoke the retro-futuristic atmosphere of early 2000s software without sacrificing legibility or layout structure.

---

## Features

* **Vanilla Stack:** Built purely with native HTML5, CSS3, and JavaScript—zero external frameworks or heavy dependencies.
* **Multi-Language Support (21 Languages):** Dynamic translation engine built with custom JavaScript data objects without page reloads.
* **Interactive Language Carousel:** Custom smooth-scrolling UI element for selecting target languages.
* **Responsive Layout:** Flexbox-based alignment accommodating various screen sizes while maintaining visual weight.

---

## Built With

* **HTML5** – Semantic structure and layout.
* **CSS3** – Custom styling, animations, translucent overlays (`rgba`), and glowing typography.
* **Vanilla JavaScript** – DOM manipulation for dynamic language switching and custom scroll intervals.
